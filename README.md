The related files for the machine learning interatomic potential for the Fe-H binary system constructed in the following paper.

Kazuma Ito, Fast and accurate Fe–H machine-learning interatomic potential for elucidating hydrogen embrittlement mechanisms, accepted in International Journal of Hydrogen Energy
 [https://arxiv.org/abs/2512.22934]

For instructions on how to use these files, please refer to the official LAMMPS documentation (https://docs.lammps.org/Packages_details.html#pkg-ml-pace).
